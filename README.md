# Tienda — sitio DEMO

Versión de demostración (v1.1.5) con modo DEMO siempre activo: datos de ejemplo guardados solo en el navegador (clave `tiendaDemo_demo`), sin nube/Supabase, sin respaldos a Drive y sin correos.

Deploy en Render: New → Static Site, Publish directory `.`, sin build command.

Clave opcional: editar `DEMO_CLAVE=""` en index.html.
